# Features

Feature-first modules. Round 1 implements only `demo/` (the widget showcase).
The remaining folders are placeholders wired into the router skeleton and will
be built out in later rounds:

- `onboarding/` — first-run baby profile setup
- `profile/` — baby profile view/edit
- `home/` — dashboard
- `tracking/` — feeding, stool, vomiting, sleep, health logging
- `analytics/` — charts and trends
- `growth/` — weight/height/head-circumference curves
- `development/` — milestones
- `settings/` — theme (incl. dark mode), preferences
- `demo/` — temporary widget + dynamic-theme showcase
